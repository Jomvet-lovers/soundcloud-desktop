## A. Offline ページ(ユーザー指摘・再現ギャップ)

### 1. ヘッダー構成が別物(HIGH / 再現)
Tauri: `h1 "Local library"`(24px semibold)+ 右クラスタ = [online/offline ラベル /
`Try online again`(オフライン時のみ)/ `Sign in`(セッション無し時・アクセント)/
**48px 円形 Play ボタン**(play-all。この一覧を再生中なら pause、現在曲が一覧内なら resume)]。
egui: `section_header`(16px)+ ボタン列のみ。Play ボタンなし。また `Try online again` が
常時表示(Tauri はオフライン時のみ)。`Sign in` の条件は同じ。
根拠: OfflinePage.tsx:114-158 / offline.rs:94-103。

### 2. 統計行に Likes coverage が無い(HIGH / 再現)
Tauri: `{cachedCount} files · {bytes} · Likes coverage {likedCached}/{likedCount}`。
egui: `{files} · {bytes}` のみ。
根拠: OfflinePage.tsx:160-163 / offline.rs:121-126。

### 3. セクション切替(Likes / Cache)が無い(HIGH / 再現)
Tauri: `Likes {n}` / `Cache {n}` の 2 タブ(rounded-lg、選択 = bg-white/10、件数付き)。
egui: タブ無し。「Liked only」チェックボックス + 「Refresh」(Tauri に Refresh は無い)。
根拠: OfflinePage.tsx:165-199 / offline.rs:210-224。

### 4. Shuffle ボタンが無い(HIGH / 再現)
Tauri: 再生可能エントリをシャッフルして再生する `Shuffle`(アイコン + テキスト)。
egui: 無し。
根拠: OfflinePage.tsx:201-211。

### 5. 「Download all likes」の位置と挙動が違う(HIGH / 再現)
Tauri: Likes セクション内のみ。実行中はスピナー + `{done}/{total}`、進捗未取得時は
`Collecting the list…`。egui: 常時表示の別行。「Enqueueing...」スピナー → 完了後に
「Enqueued N liked tracks (background)」、Cancel ボタン(Tauri に無い)。
根拠: OfflinePage.tsx:213-233 / offline.rs:131-208。

### 6. 「Clear cache」の位置が違う(HIGH / 再現)
Tauri: Cache セクション内のみ、実行中スピナー。egui: 常時表示 + Refresh 併設。
根拠: OfflinePage.tsx:235-245 / offline.rs:214-223。

### 7. 検索がタイトル/アーティストではなく URN で絞り込む(HIGH / 再現)
Tauri: 右寄せ入力欄(placeholder `Search by title or artist`、白 4% 背景 + 白 8% 枠)で
`title` / `user.username` を部分一致。egui: `Search` ラベル + 素の入力欄、照合は
`row.urn`(行にタイトルが無いため必然的にこうなっている)。
根拠: OfflinePage.tsx:247-253, 33-42 / offline.rs:212-213, 232-240。

### 8. 行の構成が別物(HIGH / 再現)
Tauri 1 行 = [40px アートワークのボタン(未キャッシュは disabled で不透明度 50、
再生中は黒 50% + Pause オーバーレイ)] [タイトル 13px white/88 + アーティスト 11px white/40]
[モノスペース 11px white/35 の長さ] [右端: 未キャッシュ = Download アイコン /
キャッシュ済み = Trash アイコン。hover で白 6% 背景]。行間は hairline (border-b white/5)。
egui 1 行 = URN 生文字 + バイト数 + stage + "liked" + Play/Remove のテキストボタン。
アートワーク・タイトル・アーティスト・長さが無い。
根拠: OfflinePage.tsx:268-319 / offline.rs:236-266。

### 9. 空状態・ロード表示が違う(HIGH / 再現)
Tauri: `Loading...`(13px white/35)/ 検索ヒット無し `Nothing matches your search` /
Likes `No liked tracks have been cached on this device yet.` / Cache `The cache is empty.`
egui: `The cache is empty.` と `Nothing matches your search` のみ。
根拠: OfflinePage.tsx:257-266 / offline.rs:227-229, 267-269。

### 10. データ層: オフラインインデックスが無い(HIGH / 再現・実装)
Tauri: `offline-index`(localStorage 相当)にいいね曲と曲メタデータを保存し、
`likedTracks`(オフライン時はインデックス、オンライン時は全件取得)と
キャッシュ在庫をマージ。在庫にしか無いファイルは
`stubTrack`(タイトル = `urn.split(':').pop()`、アーティスト空)で表示。
egui: 在庫のみ。liked メタデータ源が無く、URN 生表示になる。
実装メモ: `BootHandle.direct.store.liked_tracks`(direct/store.rs:16)が既に
いいね曲メタデータを持っているので、これをオフラインインデックスとして渡す。
在庫側は `CacheInventoryEntry` に `durationMs` / `expectedDurationMs` / `modifiedAt` が
既にある(track_cache/state.rs:329-342)。
根拠: useOfflineLibrary.ts:22-202, lib.ts:24-56 / offline.rs:51-69。

### 11. 一括 DL の進捗表示(HIGH / 再現)
Tauri: `cacheLikes.progress` の `done/total` をライブ表示。
egui: 完了メッセージのみ(進捗カウンタ無し)。
根拠: OfflinePage.tsx:220-226 / offline.rs:200-207。

## B. ピル型カード(ユーザー指摘)

### 12. ピル形状の全数調査と、カード形状の方針(HIGH / ユーザー指示 + R-11)
`CornerRadius::same(` の全 14 箇所を確認。**カード状のピル容器は存在しない**。
内訳: テーマ角丸 6(ボタン/入力)/ ウィンドウ 10・メニュー 8 / カードアート 12 /
アバター = 半径/2 の円 / 検索行アバター 18(円)/ pin アート 6 / 波形コメント 9 /
「New」バッジ 9(18px 高 = ピル。Tauri は `rounded-full` で一致)/ 検索カードの
統計チップ 4(Tauri は `rounded-full` のピルで不一致)/ カード角丸 12
(Tauri の TrackCard は `rounded-2xl` = 16px で不一致)。
R-11 の観点でカードのピル化は無いが、**ユーザー指示として「ピル型カードを使わない」を
方針に記録**し、Offline 再構築は Tauri と同じ「行 + hairline」で組む(カード容器にしない)。
根拠: 上記 grep 結果 / TrackCard.tsx:74,110-114 / FreshDrops.tsx:63-64。

### 13. カードの Like ボタンがピル状のテキストボタン(HIGH / 再現 + R-11 補足)
Tauri: ハートアイコンのみ。カード上は 24px 円形チップ(未いいね = 黒 50% + 白ハート、
いいね済み = アクセント + contrast 色)、カードの hover まで `opacity-0`。
インライン(ページ内)は 32px `rounded-lg` のハートのみ、これも hover まで非表示。
egui: `widgets::like_button` が「Like / Liked」テキスト入りの塗りピル
(トラック/プレイリストページで常時表示)。
根拠: LikeButton.tsx:42-80 / widgets.rs の like_button。

根拠: TrackCard.tsx:74 / FreshDrops.tsx:36 / widgets.rs:749,995, home.rs:262。
